What each tier enables — and what it never does

L0
Observe & report
Enables
  • Ingest all feeds, de-duplicate to assets
  • Build the graph, run reachability
  • Score paths, rank choke points
  • This dashboard, read-only
Never
  • Contact any target system
  • Send any outbound probe
  • Open tickets
Gate to L1: resolution accuracy · reachability correctness on a known topology · top-10 judged worth acting on · 100% score decomposition · coverage measured
L1
Non-intrusive validation
Enables
  • Authorized read-only checks on in-scope assets
  • Version/banner, static IAM evaluation, bucket-listable
  • Confidence (κ) rises on confirmed paths
  • Blocked steps re-planned over known edges
Never
  • Exploit, write, or change state
  • Act outside the allow-list or declared window
Gate to L2: clean safety record · false-path reduction · 100% SOC attribution to the registered identity
L2
Assisted mobilization
Enables
  • Open and assign tickets to asset owners
  • Path context attached to every ticket
  • Closure verification after a fix
Never
  • Apply any fix
  • Active validation beyond L1
Gate to L3: ticket-acceptance quality · closure-verify accuracy · a signed, scoped, time-boxed Rule of Engagement
L3
Safe active validation
Enables
  • Chained non-destructive validation under the signed ROE
  • Draft a proposed fix for human review
  • Kill-switch halts any chain instantly
Never
  • Merge or apply a fix
  • Any destructive or DoS action
  • Exceed the ROE
There is no L4. The ceiling below is permanent.
Fixed ceiling at every tier: never autonomous remediation · never a destructive action · a human owns every consequential step
Rules of Engagement: authorization first · non-destructive by default · coordinated, not covert · human gate before anything active or outbound · full audit trail. Every number on this page is synthetic. No real organization data.
